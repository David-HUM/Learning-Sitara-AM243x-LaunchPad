** INICIO BASICO

la guia de incio basico para el SDK proporcionada por TI se encuentra en: https://software-dl.ti.com/mcu-plus-sdk/esd/AM243X/12_01_00_33/exports/docs/api_guide_am243x/SDK_DOWNLOAD_PAGE.html

Para UNIFLASH la depencia faltante se puede ignorar en la instalacion.

python3, openssl, dfu-util, mono-runtime son necesarios, todos disponibles en apt.

No se instala CCS de ti, a la espera de si se quiebra si se programa desde fuera.

TI CLANG compiler toolchain 4.0.4.LTS Necesario.

Los ejecutables presentes en basic requieren permisos de ejecucion antes de abrirlos (chmod)
